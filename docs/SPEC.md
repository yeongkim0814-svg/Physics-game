# 스펙 원문 — 물리 스킬 익스트랙션 게임 웹 3D 프로토타입 (1단계)

## 목표
핵심 재미 두 가지 검증: (1) 운동량 사출기의 **반동 이동** (2) 전자기 코일의 **충전 후 방출 + 전도체 연쇄**. 그래픽/멀티/아지트/지식트리는 범위 밖.

## 기술
Vite + TypeScript + Three.js. 물리 Rapier(WASM) 우선, 불가 시 cannon-es. 1인칭 PointerLock(WASD, 마우스 조준, 클릭 발사/충전, 스페이스 점프). 에셋 없이 기본 도형+단색. `npm run dev` 로 실행.
무기·부품은 **데이터 정의(JSON/TS)** 로 분리, 수치는 한 설정 파일에 모아 코드 수정 없이 튜닝.

## 레이드 루프
- 맵 1개: 평지+장애물+높은 지형+**물웅덩이 구역**+**금속 구조물 구역**
- 스폰 → 몹 처치/탐색 → 전리품(재료) 수집 → **탈출 지점** 도달 시 성공
- 사망 시 소지 무기·재료 손실, **안전 보관함 것만 유지**(UI 없이 데이터로 가능)
- 레이드 시작 전 간단한 장착 메뉴(베이스, 부품 선택)

## 무기
무기 = 베이스 1 + 슬롯 부품. 슬롯: **전방/후방/상부** + **부전공 1개(비활성 칸만)**.
### 베이스 A: 운동량 사출기
- 재료(덩어리) 소모 발사, 질량↑ 위력↑
- 발사 시 반대 방향 임펄스(p=mv). 바닥 쏘면 점프, 뒤로 쏘면 전진 가속 → **핵심 재미, 조작감 튜닝 최우선**
- 투사체는 중력으로 휨. 연사 시 흐트러짐
- 마모는 후방 슬롯에 반동 부하로 누적(강할수록 빠름)
- 남용 방지 비용: 재료 소모, 내구도 감소 — 두 수치 설정값으로 노출
### 베이스 B: 전자기 코일
- 클릭 유지 충전(시간 비례 위력↑), 놓으면 전방 빔/아크 방출
- **전도체 연쇄**: 금속 몹/금속 구조물/물웅덩이를 따라 일정 반경 내 다른 전도체로 전파. 절연체 몹은 비전파·피해 작음
- **누전**: 물웅덩이 위에 서 있거나 연쇄가 사용자·아군에 닿으면 자기도 피해. **아군에게도 전도(팀킬 가능), 의도된 재미 — 막지 말 것**
- 충전 중 이동속도 감소
- 마모는 전방 슬롯에 과충전 시 크게 누적

## 부품 (수치 임의 시작값). 필드: {슬롯, 효과 수치 배열, 내구도 유무, 마모율}
- 공통: 손잡이(후방, 안정성↑ 이동↓, 내구도 없음), 조준기(상부, 조준 속도↑ 시야↓)
- A용: 감쇠 스프링(후방, 반동↓ 사출 속도↓)
- B용: 집속 코일(전방, 사거리·정밀↑ 충전 시간↑), 절연 피복(후방, 누전 피해↓ 연쇄 범위↓)

## 내구도
부품/베이스에 존재. **0이 되면 파괴 아님 — 그 부품 효과만 정지**(베이스 0이면 무기 전체 정지). 수리는 레이드 종료 후 자동 수리 버튼.

## 몹/환경
몹 3종: 금속(전도체, 전기에 약함), 절연(비전도, 물리에 약함), 일반. 행동: 플레이어 추적 + 근접 공격. 환경 위험: 낙하 피해, 물웅덩이 누전.

## UI(최소)
HP, 무기 상태(충전량/재료 수/부품 내구도), 탈출 지점 방향, 사망/성공 화면.

## 제외
멀티/서버, 지식 해금 트리, 아지트, 화학/생물/지구과학, 부전공 효과, 호환성 규격, 사운드.

## 완료 기준
1. `npm run dev` 실행, PointerLock 이동·조준·발사
2. A: 바닥 쏴서 점프/뒤로 쏴서 가속이 의도대로, 재미있게 느껴짐
3. B: 물웅덩이/금속 구조물/금속 몹 연쇄가 시각적으로 보이고, 누전으로 자신도 피해
4. 부품 장착에 따라 수치 변동, 내구도 0 에서 기능 정지
5. 탈출 성공/사망 시 손실 규칙 적용

## 작업 방식
단계별 작은 단위, 항상 실행 가능 상태 유지. 완성 후 튜닝할 수치·알려진 한계 정리.
