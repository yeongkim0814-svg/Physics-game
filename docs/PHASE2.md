# 2단계 결과: 아지트(허브) + 격자 인벤토리 + 연구 루프

## 구현한 것 (완료 기준 1~6)
- 허브 7화면(하단 탭): 허브 / 창고 / 분석기 / 연구대 / 작업대 / 지식 트리 / 출격 준비. 저장은 localStorage v2(`physics-extraction-save-v2`), 읽기·쓰기 모두 try/catch, 손상·구버전은 새 게임, 알 수 없는 아이템/노드만 버리고 나머지는 살림
- 출격 준비 화면은 Arena Breakout 식 2단 레이아웃: 왼쪽 장비 칸(헬멧·방어구·조끼·가방, 주무기 2·보조무기 1·근접무기 1) + 주머니/조끼/가방 격자 + 금고, 오른쪽 창고. 장비 칸은 탭(선택→칸 탭)·드래그·자동 배치로 장착/교체/해제. 무기는 분류(`BaseDef.slotClass`)가 맞는 칸에만 들어감. 조끼·가방은 장착하면 그 크기 격자(`data/containers.ts`)를 제공하고 비워야 벗을 수 있음. 헤드셋 칸 없음
- 보조무기 소형 사출기(운동량 사출기 동작을 작게), 근접무기 충격 블레이드(원뿔 범위 타격, 내구도 소모)는 레이드에서 동작
- 격자 인벤토리: 창고 10×16, 안전 보관함 2×2, 가방 8×6 (`TUNING.hub.grid`). 회전·겹침 불가·스택·정렬·자동 배치·수량 분할·버리기. 탭 선택→탭 배치(기본), 드래그, 가능=초록/불가=빨강 미리보기
- 안전 보관함: 레이드 안에서 획득(★)한 것만 입장. 사망해도 유지, 탈출하면 창고로 합쳐짐. 들고 들어간 것은 거부
- 입고 초과(창고 가득): 입고 선택 화면(자리를 만들거나 버려야 함, 저장되므로 종료해도 유지)
- 샘플 → 분석기 → 노드 확정 해금(타임스탬프). 해금 순서 A(뉴턴)→C(에너지 보존)→B(전자기)→D(상대론)→E(양자). 상위 노드는 상위 분석기(2·3단계, 작업대에서 장비 부품으로 제작) 필요
- 연구대: 해금 노드의 개량 8종(모두 장단점 교환), 재료+시간. 작업대: 제작 17종, 부품 장착/분리/교체, 수리(내구도 0 포함, 파손은 추가 재료)
- 방어구: 몸통1+보조1, 저항(충격·전기·열)과 이동속도 페널티의 교환. 내구도가 닳고 0이면 효과 정지
- 레이드: 출격 준비의 가방·무기(최대 2, F/WPN 전환)·방어구로 시작. 맵에 샘플 2곳 + 연구 재료/장비 부품 11곳 추가. BAG(B)로 가방↔안전 보관함 이동(일시정지)
- 새 베이스 C·D·E: 데이터·해금·제작·개량 흐름까지. 레이드에서는 PlaceholderWeapon(동작 없음, HUD 안내)

## 알려진 한계
- 분석·연구는 각각 동시에 1건. 분석기를 여러 개 가져도 병렬화되지 않음. 시간은 기기 시계(Date.now) 기반이라 시계를 바꾸면 조작 가능(서버 도입 시 해결)
- 샘플은 종류 1개이고 "다음 잠긴 노드"를 연다(노드별 샘플 구분 없음). 변질 필드는 `TUNING.hub.sampleSpoil` 자리만 있고 로직 없음
- 열 저항은 정의만(레이드에 열 피해 없음). 부전공 슬롯·장비 마모 없음(범위 제외)
- 레이드 중 가방을 열면 완전 일시정지(몹도 정지). 레이드 중 가방 변경은 안전 보관함 이동 때만 저장되므로, 탭을 닫으면 사망 처리(가방은 손실, 안전 보관함 내용은 유지)
- 입고 대기가 있으면 다른 화면으로 못 간다(의도). 창고 크기를 설정에서 줄이면 넘친 아이템은 입고 대기로 간다
- 가방에 못 들어가는 전리품은 바닥에 남고, 메시지만 표시된다(부분 습득 없음)
- 격자 UI: 매우 낮은 화면에서는 칸이 최소 크기(`minCellPx`)로 줄고 그래도 넘치면 세로 스크롤(그때는 터치 드래그 대신 탭 배치 권장)
- 브라우저 자동화로 검증한 것: 탭/드래그/회전/자동 배치/병합/정렬/버리기, 분석 타임스탬프(리로드 후 완료), 연구 시작, 탈출·사망 정산, 안전 보관함. 실기기 멀티터치 감각은 직접 확인 필요
- C·D·E 무기를 장착해도 레이드에서 발사되지 않는다
