# 모델 운용 (토큰 절약)

> ✓ 유효. 모든 설계 단계에서 적용.
Codex 협업은 하지 않는다. 기본 에이전트는 Sonnet, 작업별로 하위 에이전트 모델을 고른다. 하위 에이전트는 콜드 스타트 비용이 있으므로 **직접 하는 것이 더 싸면 직접 한다.**

| 작업 | 모델 |
|---|---|
| 기본: 구현·통합·리뷰 | Sonnet (직접) |
| 기계적·대량·저위험: 데이터 정의(JSON/TS), 보일러플레이트, 문서/README, 단순 UI | **Haiku** |
| 고난도: 반동 조작감 설계·튜닝 분석, 연쇄 알고리즘 디버깅, 물리 버그 원인 분석, 막힌 문제 | **Opus** |

규칙: 하위 에이전트에는 대상 파일·계약(`core/types.ts`)·완료 조건을 프롬프트에 명시하고, 결과는 `npm run check` 로 검증한다.
