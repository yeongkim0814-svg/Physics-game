# 추가 지시 (SPEC.md 에 우선 적용)

> ⚠ 1~4절(배포·터치·PS1·모바일)은 유효. 5절 이후 폐기된 익스트랙션 설계.

## 1. 배포: GitHub Pages
- `<사용자>.github.io/<저장소>/` 하위 경로에서 동작. 서버/외부 API 없음
- Vite `base: './'`(상대 경로) → 저장소명 무관. 고정이 필요하면 환경변수 `VITE_BASE=/<저장소>/`
- 에셋은 코드로 생성(텍스처는 캔버스). `.github/workflows/deploy.yml`: main 푸시 → `npm run check` → Pages 배포
- 로컬 `npm run dev` 와 배포 결과 동작 동일

## 2. 입력: 안드로이드 태블릿 Chrome 우선
- 입력 추상화(`core/input.ts`): 데스크톱(WASD+마우스 PointerLock) + 터치 통합, 같은 폴링 API
- 터치: 왼쪽 플로팅 조이스틱(이동), 오른쪽 드래그(시점), 버튼(FIRE/JUMP/USE). Pointer Events 멀티터치
- 버튼 위치·크기, 데드존, 시점 감도는 `config/settings.ts` 의 `TOUCH`
- 가로 기준, 세로면 회전 안내, 전체화면 버튼. 브라우저 제스처(스크롤/확대/길게 누르기/당겨서 새로고침) 차단

## 3. 비주얼: 90년대 후반 PS1풍 (특정 게임 에셋 사용 금지)
- 저해상도 렌더 타깃 → nearest 확대 (`render/PS1Renderer.ts`), 내부 가로 해상도 설정값
- 절차 생성 저해상도 텍스처 + nearest (`render/textures.ts`)
- 정점 스냅 / 어파인 텍스처 / 정점 조명 / 프래그먼트 안개 (`render/materials.ts`), 켜고 끌 수 있음
- 후처리: 색 양자화 + 디더 + 노이즈 (끌 수 있음). 실시간 그림자 없음
- 가독성 우선: 적/전도체/탈출 지점/위험 구역은 `CUES` 발광색·윤곽(`addOutline`)으로 구분. 전기 연쇄는 가장 밝게
- 모든 비주얼 설정은 `config/settings.ts` 의 `VISUAL`

## 4. 모바일 성능
- `PERF`: 픽셀비율 상한, 몹 수 상한, 후처리 on/off, FPS 토글, 자동 해상도(프레임 저하 시 내부 해상도 먼저 낮춤)

## 5. 추가 완료 기준
1. Pages 에서 하위 경로 에셋 오류 없이 로드
2. 터치로 이동·조준·발사·점프 동시 가능
3. PS1풍 렌더가 적용되고 설정으로 조절
4. 어두운 분위기에서도 몹·전도체·탈출 지점 식별
5. 배포 단계 안내 + 튜닝 포인트 정리
