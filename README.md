# Physics Extraction Prototype

물리 스킬 익스트랙션 게임 웹 3D 프로토타입. 스펙: `docs/SPEC.md`, `docs/SPEC_ADDENDUM.md`.

```
npm install
npm run dev     # 개발 서버
npm run check   # 타입체크 + 테스트 + 빌드
```

## GitHub Pages 배포 (초보자용)
1. GitHub 에 로그인하고 우측 상단 **+ → New repository** 로 저장소를 만든다 (이미 있으면 건너뜀). Public 권장 (Private 은 유료 플랜에서만 Pages 사용 가능)
2. 이 코드를 그 저장소에 올린다. 이미 연결되어 있다면 작업 브랜치를 **main 에 병합**한다 (GitHub 저장소 페이지의 **Compare & pull request → Merge pull request**)
3. 저장소의 **Settings → Pages** 로 이동한다
4. **Build and deployment → Source** 를 **GitHub Actions** 로 선택한다 (브랜치 선택이 아님)
5. **Actions** 탭에서 *Deploy to GitHub Pages* 워크플로우가 초록색으로 끝날 때까지 기다린다 (1~3분). 실패하면 로그를 열어 확인
6. 완료 후 `https://<사용자명>.github.io/<저장소명>/` 로 접속한다 (Settings → Pages 상단에도 주소가 표시됨)
7. 이후에는 main 에 푸시할 때마다 자동으로 다시 배포된다

저장소명을 코드에 적을 필요는 없다 (상대 경로 사용). 필요하면 `VITE_BASE=/저장소명/` 환경변수로 고정.

## PS1 레트로 그래픽 파이프라인

480×270 저해상도(16:9)에서 렌더한 후, 5단계 후처리로 90년대 PS1 미학을 재현합니다.

**후처리 순서**:
1. 깊이 윤곽선: 이웃 픽셀과의 깊이 기울기로 경계 감지
2. 색 보정: 채도↓ 대비↑ 올리브-노랑 색조 + 검정 최소값(완전한 검은색 방지)
3. 비네팅: 화면 모서리 어두워짐
4. CRT: 프레임마다 변하는 그레인 + 수평 주사선
5. 바이어 디더: 채널당 16단계 양자화 + 색 띠 제거

**팔레트**:
- 배경: 올리브/카키 톤 (자유롭게 변경 가능)
- 기능색(변경 금지):
  - Cyan (0x6fc4c0): 전도체 (금속·물웅덩이)
  - Amber (0xd89a2e): 에너지·전기
  - Green (0x7fbf6a): 탈출 지점
  - Red (0xc0452e): 적·위험

**설정 파일**: `src/config/settings.ts` 의 `VISUAL.post` 에서 강도 조정 가능.

## 튜닝 포인트

**먼저 만질 값**:
- `VISUAL.post.edge`: 윤곽선 강도 (0.5~0.8 권장)
- `VISUAL.post.saturation`: 색감 생생함 (0.6~0.8)
- `VISUAL.post.black`: 검정 최소값 (0.1~0.3)
- `VISUAL.lighting`: 조명 강도 (색 16진수 값)
- `PERF.targetFps`: 자동 해상도 하강의 기준 FPS

**실기기 검증 필요**:
- 모바일 태블릿 (Adreno 650+, Mali-G77+)에서 FPS와 자동 해상도 동작
- 터치 감도 (`TOUCH.lookSensitivity`), 버튼 위치 (`TOUCH.buttons`)
- 어파인 텍스처 왜곡 (큰 면이 가깝거나 비스듬할 때): `affineTexture` 끔

## 알려진 한계

- **색 양자화**: 16단계(4비트 RGB에 유사) 때문에 색이 띠 형태로 보일 수 있습니다. `VISUAL.post.levels` 늘리면 부드러워집니다.
- **정점 조명**: 큰 면이 평평하게 밝기가 일정할 수 있습니다. PS1 특성입니다.
- **깊이 윤곽선 거짓양성**: 기울어진 면(경사로 등)에서 윤곽선이 나타날 수 있습니다. `edgeLo`/`edgeHi` 임계값 조정으로 줄일 수 있습니다.
- 비네팅으로 인한 모서리 어두워짐: `vignette` 값을 0에 가깝게 하면 없어집니다.

## 사출기 튜닝 가이드 (T3)
모두 `src/config/tuning.ts` 의 `launcher` / `player`. 반동 Δv = m·v·recoil·recoilScale / 플레이어질량 (현재 고철 8.6, 슬래그 4.3, 주괴 17.1 m/s).
- `recoilScale`(7.5): 반동 체감의 최우선 수치. 1.0 = 현실 운동량 보존(체감 거의 없음)
- `fireInterval`(0.4): 연사 간격. Δv 가 `중력×간격`(≈8 m/s)보다 크면 연사로 계속 상승, 작으면 활강. 고철이 거의 호버링이 되는 지점
- `player.recoilSlideTime`(0.45) / `slideFrictionMul`(0.08): 지상 반동 가속이 이어지는 정도
- `player.airAccel`(6): 공중 조작력. 낮을수록 반동 운동량이 보존됨
- `projectileGravity`(12), `spread.*`, `cameraKick`: 탄도/연사 퍼짐/시점 튐
- 비용: `materialsPerShot`, `durabilityCostPerShot`, `wearPerRecoil`. 재료 질량은 `src/data/materials.ts`
- 개발 테스트: `?rear=damping_spring&top=scope` 등 URL 파라미터로 부품 장착. 재료 전환 Q / AMMO 버튼

**알려진 한계**: 낙하 피해·HP 가 아직 없어 주괴 연사로 100m 이상 올라가도 위험 부담이 없다(T8 에서 낙하 피해 연결). 실기기 조작감(터치 FIRE+JUMP 동시)은 미검증.

## 맵 (T4)
`src/data/map.ts` 한 파일이 레이아웃 전부다 (블록, 계단, 물웅덩이, 전리품, 몹 스폰, 탈출 지점). 코드 수정 없이 좌표만 바꾸면 된다.
- 구역: 남쪽 스폰(평지+엄폐물) → 서쪽 물웅덩이(섬에 주괴) → 중앙 장애물 → 동쪽 금속 구조물(캣워크 3.6m, 금속 계단) → 북쪽 고지(6m, 계단 또는 반동 점프) → 북동 탈출(기둥은 안개를 무시해 어디서든 보임)
- 전도체: `GameWorld.conductors` 에 물/금속 노드 77개(`Conductor` 계약). 인접 노드 간격 ≤ 연쇄 반경이라 구조물 전체가 이어진다. `shock()` 하면 해당 구조물이 번쩍인다 (T6 코일이 사용)
- `GameWorld.isInWater(x,z)` 는 T6 누전 판정용, `mobSpawns` 는 T5 몹 배치용
- 전리품은 가까이 가면 자동 습득 (터치에서 별도 조작 불필요)
- 계단 깊이는 캡슐 지름(0.7m) 이상이어야 한다. 계단 오르기는 `player.stepHeight`(0.5) / `stepProbe`(0.3)

## 몹 (T5)
`src/data/mobs.ts`(종류·드롭) + `tuning.mobs`(능력치·AI 거리/타이밍). 몹 수 상한은 `PERF.mobCap`.
- 금속: 튼튼·느림(HP60), **전도체**, 전기 ×2 / 절연: 빠름·약함(HP40), 비전도, 전기 ×0.25·물리 ×2 / 일반: 무특성(HP50)
- AI: 경계 거리(28m) 안에서 추적 → 1.3m 에서 정지 → 근접 사거리(1.7m)에서 **예고(0.35s, 몸이 부풀고 붉은 띠가 밝아짐)** → 그때까지 사거리 안이면 타격. 예고 중 벗어나면 헛스윙. 맞으면 경계. 계단도 오른다
- 모두 몸통에 붉은 발광 띠(적 기능색)가 있어 어두운 곳/올리브 배경에서도 식별. 종류는 실루엣으로 구분
- 몹은 `Damageable`(투사체)와 `Conductor`(코일 연쇄)를 동시에 구현. **피해 배율은 몹 내부에서 적용**하므로 호출측은 원 피해량만 넘길 것 (T6 에서 절연 배율 중복 적용 금지)
- 플레이어 HP 100, 낙하 피해 = (착지 속도 − 12) × 6 (10m 낙하 ≈ 48). 사망 처리(손실·결과 화면)는 T8

## 전자기 코일 (T6)
`?base=em_coil` 또는 화면 위 **WPN** 버튼으로 전환 (장착 메뉴는 T9). 수치는 `tuning.coil`.
- **충전**: FIRE 를 쥐면 충전(기본 1.5s 에 100%, 집속 코일은 ×1.4), 충전 중 이동 ×0.35. 놓으면 방출, 15% 미만은 불발. 100% 를 넘기면 과충전(위력 최대 ×1.5, 전방 슬롯 마모 최대 8), 150% 에서 자동 방출
- **연쇄**(`weapons/conductorGraph.ts`): 빔이 맞은 몹, 또는 맞은 지점 3m 안의 물/금속에서 시작. 구조물·물·금속 몹끼리는 연쇄 반경(6m), 플레이어·절연·일반 몹은 접촉 반경(2.5m) 안이어야 닿는다. 홉마다 피해 ×0.7, 최대 8홉. 절연/일반 몹은 맞기만 하고 전파하지 않는다. 한 노드는 최단 홉으로 한 번만 맞는다
- **누전**(막지 않음): 물 위에서 충전하면 초당 15×충전량 감전. 방출 시 발밑 물이 시작점이 되어 사용자에게 연쇄가 닿는다. 가까운 금속을 쏴도 6m 안이면 돌아온다. 팀킬도 같은 규칙. 절연 피복은 누전 ×0.4, 연쇄 반경 ×0.7
- 맵의 금속 구역은 바닥 배관으로 29개 노드가 한 망이다 (절연 피복 반경 4.2m 에서는 기둥 2개가 끊김)
- 연쇄는 전도체 **근처**면 닿는다: 금속 배관 옆에 서 있는 일반 몹도 감전된다 (버그 아님)
- 알려진 한계: 번개 선이 저해상도에서 가늘다. 구조물 번쩍임이 주된 시각 단서

## 레이드 루프와 손실 규칙 (T8)
`raid/persistence.ts`(순수 함수·테스트됨) + `RaidLoop` + `ui/EndScreen.ts`. 저장은 localStorage(`physics-extraction-save-v1`), 수치는 `tuning.raid`.
- **안전 보관함(stash)** = 사망해도 유지 / **소지품(carried)** = 레이드 중에만 존재
- 레이드 시작: 보관함의 무기 전부 + 재료 키트(`raid.kit`, 보관함에 있는 만큼)를 소지품으로. 무기가 없는 베이스는 **보급 무기**(풀 내구도, 부품 없음) 지급, 키트가 `minKitTotal` 미만이면 보급 재료로 채움 (진행 불능 방지)
- **사망**: 소지 무기·재료 전부 손실, 보관함만 유지. **탈출**(지점에서 `extractHold`=1초 버티기): 소지품 전부(마모된 무기 포함)를 보관함으로
- 결과 화면: 증감/손실 내역, **자동 수리 후 새 레이드**(아지트 수리 대체, 탈출 시) / 수리 없이 새 레이드
- ⚠ **레이드 도중 새로고침/탭 닫기 = 사망 처리** (소지품이 저장된 채 남으므로 다음 로드 때 손실). 탭을 닫아 손실을 피할 수 없게 한 규칙
- 무기 전환(WPN)은 소지한 무기를 순환하며 위치/상태를 유지한다. 장착 메뉴·부품 선택은 T9

## 화면 안정화 (T8 수정)
- 계단: 올라설 때 카메라만 부드럽게 따라온다 (`player.stepSmoothing`). 프레임당 카메라 점프 0.37m → 0.07m
- 깜빡임: 텍스처 밉맵(멀리서만 평균, 가까이는 픽셀 유지) + 큰 면을 8m 조각으로 분할(`VISUAL.maxPolySize`). 물 깜빡임 지표 3.0 → 0.6

## 터치 입력 (멀티터치 · 전력질주)
`core/touch.ts` + 순수 판정 `core/touchMath.ts` (테스트됨), 설정은 `settings.ts` 의 `TOUCH`.
- **포인터 표**: 손가락(pointerId)마다 역할(move/look/fire/jump/swap)을 배정해 한 표로 관리. 시작만 터치 레이어에서 받아 **화면 좌표로** 역할을 정하고(버튼은 표시 전용), 이동/끝은 window 에서 받는다 → 포인터 캡처·이벤트 대상 요소에 의존하지 않는다
- 조이스틱 손가락(왼쪽 40%)과 시점 손가락은 독립. 조이스틱이 있을 때 왼쪽 영역의 두 번째 손가락은 시점. **FIRE 를 누른 손가락을 끌면 시점이 돈다**. 같은 버튼을 여러 손가락이 눌러도 모두 떼야 해제
- 놓친 `pointerup` 복구: touchend/touchcancel 때 실제 접촉 목록과 대조해 남은 포인터 정리. 포커스를 잃으면(알림/홈/탭 전환) 전부 초기화
- **TOUCH 버튼(화면 위)**: 진단 표시. 인식 중인 손가락과 역할(`touch 현재/최대`), down/up/cancel/healed/ignored 카운터를 보여준다. 기기에서 멀티터치가 안 될 때 이 화면을 캡처해 원인 확인
- **전력질주 잠금 (PUBG/Arena Breakout 방식)**: 조이스틱을 림 끝까지 밀면 위쪽에 잠금 아이콘(▲▲)이 나타나고, 손가락을 그 아이콘까지 끌어올리면 잠긴다. 손잡이가 아이콘 자리에 고정되고 손을 떼도 유지. 이동속도 ×1.5(`player.sprintMul`), 방향은 시점으로. **해제: 왼쪽 영역 재터치**. 오른쪽 시점/버튼 터치는 해제하지 않는다
  - 아이콘은 림 바깥에 있어(`sprint.iconDistance` 1.6배) 평소 최대 전진으로는 잠기지 않는다 (불변식이 테스트로 고정됨)
- 데스크톱: Shift 를 누르는 동안 전력질주
- 터치 버튼은 FIRE / JUMP / AMMO 만 있다. 상호작용은 추후 설계 (키보드 E 입력만 `interactPressed` 로 남아 있음)
